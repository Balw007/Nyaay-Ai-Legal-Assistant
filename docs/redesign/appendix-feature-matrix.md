# Nyaay — Feature-preservation matrix (Next.js frontend vs FastAPI backend)

Read-only audit of `/home/claude/nyaay` (2026-11-23). Paths: frontend = `web/src/...`, backend = `app/...`.
All frontend requests go through `web/src/lib/api.ts` → `fetch('/api' + path)`; `web/next.config.ts:17-19` rewrites
`/api/:path*` → FastAPI (`NYAAI_API`, default `http://127.0.0.1:8000`) with `proxyTimeout` 15 min and
`proxyClientMaxBodySize` 60 MB (`next.config.ts:9-14`). Every request sends `X-Requested-With: nyaai`
(`lib/api.ts:26`) — **mandatory**: the backend rejects any POST/PUT/PATCH/DELETE without it with 403
(`app/main.py:41-45`, webhooks excepted). Session = httpOnly cookie `nyaai_session` (`app/deps.py:19,31`), sent via
`credentials: "same-origin"` (`lib/api.ts:24`). A 401 on any request redirects to `/login?next=<path+search>`
(`lib/api.ts:36-38`). 502/504 → "Nyaai server is not running" message (`lib/api.ts:16`).

Plain `<a href>` downloads that bypass `api.ts` (so carry the cookie but no custom header; all are GETs, which is fine):
`/api/drafts/{id}/export?format=docx`, `/api/firm/export`, `/api/system/review-pack?format=docx|md`,
`/api/calendar.ics?download=true`, `/api/matters/{id}/calendar.ics?download=true`.

Roles (`app/deps.py:22` `ROLE_RANK = clerk 0 < advocate 1 < admin 2 < owner 3`). Frontend helpers:
`canApprove(role)` = owner|admin|advocate, `isAdmin(role)` = owner|admin (`lib/hooks.ts:18-19`).

## 4. Inventory of client-side contracts a redesign must keep

**localStorage keys**: `nyaay-theme` (`dark`|`light`; default dark) — `app/layout.tsx:14`, `components/providers.tsx:13,32`; `nyaay-reader-size` (`0|1|2`, default 1) — `judgments/[id]/page.tsx:25,41`. No sessionStorage, no other cookies set by the frontend.

**URL query params / hashes**: `/login?next=&invite=`; `/research?q=&court=&from=&to=&offset=&ask=`; `/judgments/{id}?para=` (target element id `para-{n}`, `judgments/[id]/page.tsx:166`); `/citations?id=&matter=`; `/matters?new=1`; `/settings#profile|chambers|team|ai|review|holidays|data`; `/matters/{id}/routes?<playbook_input>=YYYY-MM-DD` (API). Judgment ids are `encodeURIComponent`-ed in every link.

**Keyboard shortcuts**: Ctrl/Cmd+K command palette (`command-palette.tsx:41`); Ctrl/Cmd+F find in judgment, Esc close, Enter/Shift+Enter next/prev (`judgments/[id]/page.tsx:76-77,121`); Ctrl/Cmd+S save draft (`drafts/[id]/page.tsx:62`); Esc closes drawers (`matters/modal.tsx:12`).

**Confirm dialogs (native `confirm`)**: batch approve/reject (`approvals/page.tsx:67`); delete draft (`drafts/[id]/page.tsx:141`); delete note (`tabs.tsx:352`); remove example data (`library/page.tsx:109`); remove Telegram bot (`connect-panels.tsx:61`); revoke calendar link (`connect-panels.tsx:114`). Typed `ERASE` for erase matter (`tabs.tsx:435-436`).

**Polling**: `/health` 60 s, `/tasks?status=proposed` 60 s (`lib/hooks.ts:9,14`); `/library/status` 1.5 s while a job runs, else 15 s (`library/page.tsx:44`).

**Known defects / gaps found (do not "preserve" accidentally; decide deliberately)**:
1. `#p{n}` anchors in AuthoritiesTab (`tabs.tsx:377`) and OpposingPanel (`tools.tsx:170`) don't jump; reader expects `?para=`.
2. Bookmarks with no matter are write-only in Next (see §3.2).
3. "Approve all safe" tooltip says client messages are never included (`approvals/page.tsx:86`), but order-derived "Send client update" tasks have `action=null` (`app/routes/orders.py:45-46`) and therefore *are* in `safe_ids` (`app/routes/tasks.py:158-161`). (Approval sends nothing; it only marks it approved.)
4. Calendar page renders `type:"task"` events as hearings (`calendar/page.tsx:72,87`).
5. Dashboard "No deadlines in the next 14 days" but backend window is 21 days and includes all overdue (`app/routes/workspace.py:395`).
6. `/library/status` and `/library/hc-courts` are advocate+; clerks see an error on Library. `/metrics` is admin-only; non-admins see an error panel in Settings→Data. Holiday writes need advocate+ but UI doesn't disable for clerks.
7. Key dates cannot be cleared from the UI (empty values filtered `tabs.tsx:41`; backend merges `matters.py:89-91`).
8. TS type drift: `CheckStatus` lists `NOT_SUPPORTED`, `NOT_FOUND`, `OVERRULED` (never emitted); `AskResponse.mode` mentions `no_results` (backend emits `no_sources`); `MatterDetail` declares `drafts/notes/bookmarks/checks` (backend never returns them) (`lib/types.ts:33,46,92-95`).
