# Running a pilot with practising advocates

Goal: prove that 5–10 advocates doing NI Act s.138 work come back every week without being asked.

## Before the pilot (week 0)
1. One advocate (the advisor) signs off every rule, stage and template in Settings → Advocate review, or
   requests changes. Fix the requested changes before going live.
2. Import the court holiday lists for the courts the pilot firms appear in (Settings → Court holidays).
3. Load SC judgments 2010–2025 and the relevant High Court(s). Build semantic search (`ingest embed`).
4. Set up WhatsApp and eCourts tokens if budget allows; they make the product habitual.

## Onboarding (30 minutes each)
- Create their real matters (CNR included) together; confirm the dates from the files.
- Forward one real order on WhatsApp together. Approve the proposed tasks together.
- Ask them to use "Ask" for one real research question that week.

## What to watch (Settings → Usage & pilot)
| Signal | Healthy by week 4 |
| --- | --- |
| Active this week / users | ≥ 70% |
| AI proposals accepted | ≥ 60% (lower = the order reader or playbook is wrong) |
| Thumbs down with comments | each one read and answered within a week |
| Zero-result searches | falling; each one is a missing synonym or missing data |

## Interview questions (end of weeks 1 and 4)
1. What did you do in Nyaai this week that you would otherwise have done by hand?
2. Was there any moment you did not trust what it showed you? What was it?
3. What did you still do in your diary, WhatsApp or Excel instead? Why?
4. If Nyaai disappeared tomorrow, what would you miss? (If "nothing", the pilot has failed — find out why.)
5. Would you pay ₹___ a month for it? Who in your chambers decides?

## Stop / continue
Continue only if at least half the advocates answer question 4 with something specific.
